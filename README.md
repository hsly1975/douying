# GKD 抖音短剧中间广告跳过规则

让 GKD(一个基于无障碍服务的自动化工具)在抖音看短剧时,遇到中间插播的广告(出现"上划继续观看"提示),**自动上划跳过**,不用手动划。

## 这是什么

- **GKD**(GitHub - https://github.com/agegr/GKD)是一个开源的 Android 无障碍自动化工具,可以按规则自动点击/滑动屏幕上的元素。
- 本仓库提供一条**自定义规则** `douyin_drama_ad_skip.json5`:
  - 匹配抖音(`com.ss.android.ugc.aweme`)界面上出现"上划继续观看"/"上滑继续观看"文字的元素;
  - 匹配到后,从屏幕 70% 高度处上滑到 30% 高度处(模拟手指上划),300ms 完成;
  - 动作冷却 2 秒,避免连续误触发。

## 安装步骤(手机)

### 1. 安装 GKD

- 从 GitHub 下载 GKD 的 APK:https://github.com/agegr/GKD/releases
  - 选 `GKD.apk`(或带版本号的那个),下载后安装。
- 安装后打开 GKD,按提示**授予无障碍权限**:
  - 系统设置 → 无障碍/辅助功能 → 已下载的服务 → GKD → 开启。
- 建议同时授予**通知权限**和**电池优化白名单**(防止后台被杀)。

### 2. 添加本规则订阅

GKD 里 → **设置** → **订阅管理** → **添加订阅**,填入:

```
https://github.com/hsly1975/douying/raw/main/douyin_drama_ad_skip.json5
```

- 订阅名称随意,比如"抖音短剧跳广告"。
- 添加后点**刷新/更新**,确认能看到规则"短剧中间广告-上划跳过"。

> 如果 GitHub 访问慢,可以先在电脑浏览器打开上面这个链接,复制全部 JSON 内容,然后在 GKD 里用"手动导入/粘贴规则"的方式导入。

### 3. 启用规则

- 回到 GKD 主界面 → **规则列表**,找到"短剧中间广告-上划跳过",打开开关。
- 确认 GKD 顶部状态显示"运行中"。

### 4. 使用

- 正常打开抖音刷短剧。
- 广告出现"上划继续观看"提示时,GKD 会自动上划跳过,直接进入下一集。
- 不需要任何手动操作。

## 工作原理

| 项目 | 值 |
|------|-----|
| 触发条件 | 屏幕上出现包含"上划继续观看"或"上滑继续观看"文字的元素 |
| 执行动作 | 上滑:屏幕中点 (50%, 70%) → (50%, 30%),耗时 300ms |
| 冷却时间 | 2 秒(防止连续触发) |
| 作用范围 | 仅抖音 App(`com.ss.android.ugc.aweme`) |

## 常见问题

**Q: 广告出现但没自动跳过?**
- 确认 GKD 无障碍权限已开、状态"运行中"。
- 确认规则开关已打开。
- 抖音版本更新后文案可能变化(比如改成"上滑观看下一集"),告诉我实际文案,我更新匹配规则。

**Q: 会不会误触发(正常看剧时乱滑)?**
- 不会。规则只在出现"上划继续观看"这类广告提示文字时才触发,正常剧集画面没有这个文字。

**Q: 想调整滑动速度/幅度?**
- 改 `douyin_drama_ad_skip.json5` 里的 `swipeArg`(start/end 坐标、duration),然后 `git push`,GKD 里点"更新订阅"即可。

**Q: 怎么更新规则?**
- GKD → 订阅管理 → 找到本订阅 → 点"更新"。
- 或者等 GKD 自动更新(如果开了自动更新)。
